# 十课学习路径

十课按依赖顺序推进。你先建立可信评测，再创建和修改 Skill。Gate 与 Registry 在最后阶段接管版本决策。

<CourseMap />

## 四个阶段怎样接上

1. **看见与判分：** 先建立公平对照，再用终态和轨迹判断任务是否真正完成。
2. **让评测可信：** 校准 Judge，固定运行条件，并让中断后的实验可以恢复。
3. **从数据创建 v0：** 把有来源的数据加工成案例，再创建第一份可测试 Skill。
4. **有证据地进化：** 从失败生成候选，让独立 Gate 决定接受、拒绝、晋升或回滚。

你不需要提前挑课。按顺序完成即可，因为每个阶段都会使用前一阶段留下的证据。

## 每课页会告诉你什么

- 你要解决的判断问题。
- 学完后应该具备的能力。
- 本课主要证据及其边界。
- 可以运行的 fixed/offline 命令。
- 当前维护者测试与学习者验收的区别。
- 完整讲义、starter、solution 和参考结果入口。

## 学习时守住三条线

1. **不要从 solution 开始。** 先写下你认为系统需要保证的不变量，再实现 starter。
2. **不要把固定参考当成实际效果。** 它用于理解协议、数据流和证据结构。
3. **不要只看总分。** 每次结论都要能回到运行、状态、断言和版本事件。
