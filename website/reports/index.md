# 报告中心

报告不是漂亮的结课截图。它是从结论回到证据的入口。

课程把报告分成三层。每一层只回答自己的问题，不越权替下一层下结论。

## 推荐阅读顺序

1. 先读 L1，学会从汇总回到单次运行。
2. 再读 L2，理解公平配对和变化分类。
3. 最后读 L3，理解 Gate 与 Registry 怎样约束自动循环。

这里展示的都是清洗后的学习摘要。站点不公开原始报告文件，也不展示受保护案例、逐题 final 结果或修改者无权读取的材料。
