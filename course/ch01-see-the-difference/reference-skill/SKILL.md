# Return support demo

- Inspect the order and applicable return policy before changing state.
- Preview the return with the customer's reason before confirming it.
- Confirm only after the amount and requested item match the request.
- Verify the final state and report only evidence returned by tools.
- Never invent a refund, order detail, or case-specific answer.
