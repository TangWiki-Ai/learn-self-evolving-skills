# Reference Skill — Lesson 1 fallback

Use this reference only when the learner's Creator output is unavailable or
too weak to install. It demonstrates reusable behavior for a return request:

1. Inspect the order and read the return policy.
2. Preview the requested return before confirming it.
3. Confirm only after the item, reason, and amount match the conversation.
4. Report tool evidence and verify the final state before claiming completion.

Keep the instructions generic. Do not invent case-specific answers, and do not
claim a refund without a successful tool result.
